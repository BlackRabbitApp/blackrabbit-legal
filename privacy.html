Политика конфиденциальности · Privacy Policy

Обновлено · Updated: 3 мая 2026 · May 3, 2026

Описание обработки данных расширением BlackRabbit для Chrome. Оператор — издатель расширения. How the BlackRabbit Chrome extension processes data. Controller: the extension publisher.

1. Данные · Data

  • Текст для перевода — ввод и контекстное меню «Перевести в BlackRabbit». Text to translate — your input and the context menu action.
  • Настройки UI — языки, мини-кролик, состояние панели (локально). UI settings — languages, mini-rabbit, panel state (local).
  • ID устройства для лимитов — случайный, локально; на сервер перевода/биллинга для квот и Pro. Device ID for quotas — random, local; sent to translation/billing for quotas and Pro.
  • Счётчики перевода — дневной лимит (локально и/или на сервере). Usage counters — daily cap (local and/or server).
  • Буфер обмена — только по вашему действию (вставка / двойной клик), не в фоне. Clipboard — only when you act (paste / double-click), not in background.

2. Хранение · Storage

  • chrome.storage.local — настройки, ID, план Free/Pro, использование за день. chrome.storage.local — settings, ID, Free/Pro, daily usage.
  • chrome.storage.session — кратко: состояние фонового аудио; не передаётся сайтам. chrome.storage.session — short-lived background audio state; not sent to sites.

3. Перевод · Translation

Текст уходит в сервис перевода. Режимы: (а) через backend (Cloudflare Worker) — ID, языки, фраза; квоты; без долгого хранения по замыслу; (б) напрямую из расширения — условия провайдера перевода. Text goes to a translation service. (a) Via backend (Worker): device ID, languages, phrase; quotas; not meant for long retention. (b) Direct from extension: provider terms apply.

4. Разрешения Chrome · Permissions

  • storage — настройки и квоты. Settings and quotas.
  • tabs — панель, синхронизация вкладок, стоп аудио. Panel, tab sync, stop audio.
  • clipboardRead — только ваши действия. Only actions you initiate.
  • contextMenus — «Перевести в BlackRabbit». Context menu translate.
  • host_permissions — домены перевода и при необходимости сервер издателя. Translation domains and publisher server if listed.

5. Контент-скрипты · Content scripts

UI в изолированном контексте расширения. Сборка CWS не внедряет MAIN-world скрипты на YouTube и др. UI in the extension isolated context. Store build does not inject MAIN-world scripts on YouTube etc.

6. Игры и аудио · Games & audio

Внутри расширения; файлы из пакета. Содержимое вкладок на сервер издателя не отправляется. Inside the extension; assets from the package. Tab content is not sent to our servers.

7. Оплата Pro · Payments (CryptoCloud)

Провайдер — CryptoCloud. Полные реквизиты карт расширение/страница оплаты не хранят. В URL оплаты может быть deviceId для привязки Pro к установке; счёт создаётся через Worker, в CryptoCloud — минимум данных для счёта. CryptoCloud processes payment. We don’t store full card data. Checkout URL may include deviceId to tie Pro to your install; invoice via Worker with minimal data to CryptoCloud.

8. Дети · Children

Не направлены на сознательный сбор данных о детях до 13 лет. Not aimed at knowingly collecting data from children under 13.

9. Изменения · Changes

Политика может обновляться; актуальность — по дате выше. Продолжение использования означает принятие изменений, если иное не требует закон. Policy may change; date above is current. Continued use means acceptance unless law says otherwise.
