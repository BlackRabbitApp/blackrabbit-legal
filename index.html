Настоящая политика описывает, как расширение BlackRabbit для браузера Chrome (далее — «Расширение») обрабатывает данные. Оператором по отношению к данным пользователя является лицо, опубликовавшее Расширение.

1. Какие данные обрабатываются

  • Текст для перевода — вводится вами в поле Расширения или передаётся через контекстное меню «Перевести в BlackRabbit».
  • Настройки интерфейса — например выбранные языки, параметры мини-кролика, состояние панели (локально на устройстве).
  • Технический идентификатор устройства для лимитов — случайный идентификатор, создаётся Расширением и хранится только локально; может передаваться на ваш сервер перевода (если он настроен).
  • Счётчики использования перевода — для отображения дневного лимита (локально и/или на сервере при подключённом backend).
  • Буфер обмена — читается только при явном действии (вставка / двойной клик по полю ввода), не в фоне.

2. Где хранятся данные

  • Локально в браузере (chrome.storage.local): настройки, идентификатор устройства для квот, сведения о плане Free/Pro для отображения в UI, данные о дневном использовании перевода (если сервер перевода не используется).
  • Сессия браузера (chrome.storage.session): краткоживущие сведения о состоянии фонового аудио между перезапусками компонента фона — без передачи на сторонние сайты.

3. Перевод текста и передача третьим лицам

Чтобы выполнить перевод, текст запроса отправляется на сервис перевода. Возможны два режима (зависит от сборки и настроек разработчика):

  • Через backend (рекомендуется), например Cloudflare Worker: на сервер уходят идентификатор устройства, выбранные языки и текст фразы; сервер обращается к API провайдеров перевода и может вести учёт квот.
  • Без отдельного сервера: запрос к API перевода выполняется из фона Расширения.

4. Разрешения Chrome и зачем они нужны

  • storage — сохранение настроек и квот.
  • tabs — показ панели перевода на активной вкладке, синхронизация UI между вкладками, остановка аудио на другой вкладке.
  • clipboardRead — только для вставки текста по вашему действию.
  • contextMenus — пункт «Перевести в BlackRabbit» для выделенного текста.
  • host_permissions — доступ к доменам перевода и при необходимости к вашему Cloudflare Worker.

5. Контент-скрипты

Интерфейс перевода и связанная логика выполняются в изолированном контексте расширения на страницах, соответствующих шаблону в манифесте.

6. Мини-игры и аудио

Игры и звуковые петли выполняются внутри Расширения; аудиофайлы загружаются из пакета Расширения.

7. Оплата и Pro

Оформление платной подписки (если включено) выполняется через сторонний платёжный сервис. Расширение не хранит полные данные банковских карт.

8. Дети

Расширение не ориентировано на сбор данных о детях младше 13 лет сознательно.

9. Изменения

Политика может обновляться; актуальная версия — по дате вверху страницы.

Privacy summary (English)

BlackRabbit is a Chrome extension for translation, calculator, mini-games, and optional background audio. Translation text is sent to a translation API (via a developer-operated Worker or from extension background). Settings, a random device id for quotas, and usage counters are stored in chrome.storage.local; short-lived audio state may use chrome.storage.session. Clipboard is read only on explicit user paste actions.
